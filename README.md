# WaveGenQ

WaveGenQ means Wave-Generator-Quick.

A browser-based tool for generating waveform images from audio files with customizable colors and transparent backgrounds.

## Features

- Audio file support: MP3, WAV, OGG, M4A
- Customizable waveform and background colors
- PNG export with options for:
  - Transparent background
  - White or custom colored background
- Two sizing modes:
  - Time-based: Automatically calculates width based on audio duration (pixels per second)
  - Fixed size: Manual width and height control
- Light/dark theme toggle
- No installation required - runs directly in browser

## Quick Start

1. Clone this repository and open the folder in Visual Studio Code
2. Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension
3. Right-click `index.html` and select "Open with Live Server"
4. Upload an audio file, customize settings, generate the waveform, and export as PNG
